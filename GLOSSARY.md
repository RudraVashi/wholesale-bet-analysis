# Formcast glossary

Plain definitions for the jargon on the desk. Also see the **Fan take** box on every dossier.

## Board / workflow

| Term | Meaning |
|------|---------|
| **Slate** | Today’s list of bets / games to look at. |
| **Dossier** | Deep dive on one bet — scores, recent games, news. |
| **Power (Power play)** | PrizePicks entry with 2–4 player overs/unders that all need to hit. |
| **Journal** | Your saved picks + win/loss grades (stored in your browser). |
| **Manual paste** | Type PrizePicks lines yourself when the auto board is blocked. |

## The scorecard

| Term | Meaning |
|------|---------|
| **Wholesale form (L10 / L20)** | How often the player cleared (or stayed under) this number in their last 10 / 20 games. “Wholesale” = big recent sample, not one random game. |
| **Last 5** | Hit or miss in each of the five newest games on file, the same kind of strip PrizePicks shows. Tonight’s game is not in it. |
| **Next game after a streak** | Inside this log, take every game that was played right after a given last-5 result (for example 5 hits in the five before it) and count how often that next game hit. Fewer than 3 of those next games is too thin to lean on. |
| **Hit rate** | Percent of those games that would have won the over (or under). |
| **Team dynamics / Home-away** | Home vs away splits, rest, back-to-backs. Venue matters a lot. |
| **Performance** | Season-ish average vs the line + how streaky they are. |
| **Off-pitch** | Stuff outside the box score: injuries, lineup news, drama, travel (Gemini write-up). |
| **Line value** | Whether *our* lean looks better than what the market price implies. |
| **Contrarian** | Numbers say one thing, the story/news says another. |
| **Composite / score** | Weighted blend of the factors (0–100). Higher ≠ guaranteed win. |
| **Confidence / conf** | How much we trust that score (sample size, thin edges, bad news). |
| **Stinker check** | Soft “this might be a trap / force” warning. |
| **Edge** | Rough “how far above mediocre” the form+value combo is. Positive is more interesting. |
| **Verdict / recommended side** | over, under, home, away, or **pass**. |
| **Pass** | Skip it. No clear side. |

## Betting / market words

| Term | Meaning |
|------|---------|
| **Line** | The number (e.g. 27.5 points). |
| **Over / Under** | More or less than the line. |
| **Moneyline / match winner** | Who wins the game (home / away / sometimes draw). |
| **Implied probability** | What the odds *say* the chance is (e.g. -150 ≈ ~60%). |
| **PRA** | Points + rebounds + assists. |
| **SoT** | Shots on target (soccer). |
| **Props** | Bets on player stats, not just who wins. |
| **Same-game stack** | Multiple legs from one game — they move together (riskier Power). |

## Platforms here

| Term | Meaning |
|------|---------|
| **PrizePicks** | DFS-style player prop board (your main playground). |
| **Polymarket** | Prediction market — often match winners. |
| **TheOddsAPI / sportsbook** | Traditional book moneylines (NBA on free tier). |
| **ESPN fixture** | Game time + teams from ESPN when we don’t have a book price (common for EPL on free data). |

## How to read a dossier in 20 seconds

1. Read the **Fan take** first.  
2. Check **kickoff time** and **home/away**.  
3. Glance at **L10 hit rate** and the **Last 5** dots vs the line. If the next-game note says the sample is thin, don’t treat a hot streak as a tell.  
4. If **stinker** is on or confidence is low → default to pass.  
5. Only then dig into the factor cards.
